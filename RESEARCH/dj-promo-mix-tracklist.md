## Mix Notes

**Tempo Arc:** 50 → 60 → 70 → 85 → 90 → 110 → 120 → 130 → 174 → 120 → ambient
**Energy Curve:** Stillness → breath → pulse → tension → peak → release → drift
**Genre Journey:** Devotional drone → generative ambient → cosmic synthwave → intimate vocal → driving synthwave → peak techno → DnB → ambient techno → cosmic drift

**Why this order:**
- Opens with the most patient, atmospheric material (Brindavan Gardens, The Manteis Project) to establish mood
- Builds through Red Shift Mantra's synth architecture — the bridge between ambient and rhythmic
- Bethany Pritchett provides a human vocal moment at the midpoint — contrast and relief
- Peaks with Thesan Musique's techno and DnB — the dancefloor payload
- Returns to ambient for the comedown — the mix resolves where it began, in stillness

**Technical requirements for Rhett:**
- Record in Ableton Live 12 with the full catalog loaded
- Use Live's warping for tempo transitions — set warp markers at transition points
- Keep transitions smooth — long crossfades (8-16 bars) for ambient, quick cuts for peak section
- Master to -14 LUFS for SoundCloud, -16 LUFS for Spotify
- Export: 320kbps MP3 + WAV master
- Artwork: use the Red Shift Mantra Deep Field Image cover or a custom mix cover with the Manteis Recordings logo

**Distribution plan:**
1. Upload to SoundCloud (public) with full tracklist in description
2. Upload to Mixcloud (public) — better for long-form mixes, no length limits
3. Create private SoundCloud link for venue bookers — include in outreach emails
4. Share link in venue outreach emails (see outreach/venue-outreach-2026-08-16.md)
