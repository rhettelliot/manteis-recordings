### DistroKid Upload Checklist (for whichever release Rhett chooses)

**Audio Files:**
- [ ] Mastered WAV files (16-bit, 44.1kHz minimum — 24-bit preferred)
- [ ] Each track loudness-normalized to -14 LUFS (Spotify standard)
- [ ] ISRC codes (DistroKid auto-generates if not provided)
- [ ] No clipping, no silence longer than 2 seconds at start/end

**Cover Art:**
- [ ] 3000x3000px minimum (square, JPG or PNG)
- [ ] No social media handles, URLs, or text beyond artist name + title
- [ ] No copyrighted images
- [ ] No blurry/low-res images

**Metadata (per track):**
- [ ] Track title (exact spelling)
- [ ] Artist name (exact match to Spotify profile)
- [ ] Album title
- [ ] Genre and subgenre (select from DistroKid's list)
- [ ] Release date (set at least 4 weeks out for Spotify editorial pitch window)
- [ ] Composer/lyricist credits
- [ ] Explicit content flag (if applicable — unlikely for Manteis catalog)
- [ ] Language of lyrics/metadata

**DistroKid Options to Enable:**
- [ ] **Spotify/Apple Music pre-save** (HyperFollow page — auto-generated)
- [ ] **YouTube Content ID** (monetize on YouTube — opt in for all instrumental tracks)
- [ ] **Facebook/Instagram Stories** (allows fans to use 15-sec clips in Stories)
- [ ] **TikTok** (allows fans to use sound in TikTok videos)
- [ ] **Shazam** (enable for discovery)
- [ ] **Pandora** (submit for consideration)
- [ ] **Custom release date** (not "release immediately" — set the date)

**DistroKid Options to SKIP:**
- [ ] ~~DistroKid's "Leave a Legacy" ($2.99/year per release)~~ — unnecessary, DistroKid keeps releases up as long as subscription is active
- [ ] ~~Album extras (cover song licensing, etc.)~~ — all Manteis material is original

### Post-Release: DistroKid Analytics

- **Daily sales stats** (Musician Plus) — check weekly
- **Streaming platform breakdown** — which platforms generate most plays
- **Geographic data** — where are listeners? (Seattle expected to be #1)
- **Playlist data** — which playlists are driving discovery?
- **Revenue** — DistroKid pays monthly once threshold is met. Revenue splits: DistroKid takes 0% of streaming royalties (subscription model). Keep 100%.
